Upbit LSTM Trader

View on GitHub

An end-to-end crypto trading research pipeline for the top-5 KRW markets on Upbit. It collects 5-minute candles, trains a 2-layer LSTM on a local GPU (RTX 5060) to forecast 30-minute returns, and runs the exported ONNX model every five minutes on a free-tier Oracle Cloud CPU instance — in paper-trading mode by default.

  • Leakage-aware evaluation — chronological train / validation / test split with label purging at the boundaries; scalers and buy thresholds are fitted on past data only.
  • Model comparison — a Gaussian HMM baseline evaluated against the LSTM on the same bars, trading costs and risk limits.
  • Execution safeguards — performance gates before any live order, stop-loss / take-profit and drawdown limits, and duplicate-safe order handling.
Python PyTorch LSTM HMM ONNX Runtime Oracle Cloud

Built for learning and research — not investment advice.
